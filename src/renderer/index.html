Engine

Step 1 of the pipeline: turns your voice into raw text. The AI that polishes it is a separate choice on the AI & Refinement tab.

Engine —
Detail —

Checking...

NVIDIA Parakeet running on-device via parakeet.cpp. Faster and more accurate than Whisper on English, and the v3 models cover 25 European languages plus Japanese.

Trade-off: Parakeet accepts no initial prompt, so your Vocabulary and learned project jargon cannot steer recognition the way they do for Whisper. Names and domain terms get corrected afterward by the refiner instead, which needs an LLM provider set. If jargon accuracy matters more than raw speed, stay on Whisper.

Uses macOS's built-in on-device Speech Recognition. Grant the Speech Recognition permission on the General tab. No API key needed.

Step 2 of the pipeline: the LLM that cleans up the raw transcript — removes fillers, fixes grammar, applies your prompt. Choose None to insert the raw transcript with no AI.

No API key needed — this uses your existing CLI auth. Make sure claude or codex is installed and authenticated.

llama-3.3-70b-versatile (default) is accurate and still fast. llama-3.1-8b-instant is cheaper but less reliable: it can drop or change words.

Static IAM credentials, signed with SigV4. Assumes an Anthropic Claude model on Bedrock.

Features

Tune refinement per app. Prompt keeps every detail for AI agents (Cursor, ChatGPT, Claude); Coding preserves identifiers; Shell preserves command syntax. Overrides the automatic default for that app.

Conversation Memory

Feeds your most recent dictations to the Refinement Engine as background context, so it can resolve pronouns like "it" or "that" and keep a consistent train of thought across separate recordings. Pulled from your local run log; only the count below is sent to your chosen provider.

Vocabulary List

High-priority terms injected into every refinement. One per line, or comma-separated.
